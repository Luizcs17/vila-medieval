# Músicas

O jogo toca estes arquivos se existirem (veja `src/audio/sound.ts` e `docs/CREDITS.md`):

- `title.mp3` — tela inicial
- `day_kingdom.mp3`, `day_majesty.ogg` — dia
- `night_legend.mp3`, `night_theme.mp3` — noite
- `battle.mp3` — batalha

Sem os arquivos, o jogo fica sem música (os efeitos sonoros são sintetizados e sempre funcionam).
